# Política de segurança

## Reporte responsável

Não abra uma issue pública para relatar credenciais expostas, dados pessoais, acesso indevido a arquivos, uso não autorizado da marca ou outro problema sensível.

Envie o relato para [kaue.ruon@gmail.com](mailto:kaue.ruon@gmail.com), com uma descrição do impacto, os arquivos ou links envolvidos e passos seguros para reproduzir o problema quando necessário.

## Escopo deste repositório

Os riscos mais relevantes aqui são:

- credenciais ou arquivos locais enviados por engano;
- assets de terceiros sem licença ou atribuição adequada;
- materiais internos publicados antes de aprovação;
- arquivos de impressão enviados com medida, versão ou instrução incorreta.

Não publique anexos confidenciais nem dados de clientes no reporte. O recebimento será confirmado e a correção será coordenada em canal privado.

## Cuidados ao contribuir

- Nunca versione arquivos `.env`, chaves, tokens ou dados de clientes.
- Confirme licenças de fotos, fontes, ilustrações e mockups antes de adicioná-los.
- Use Git LFS para os formatos já configurados no repositório.
- Revise o destino e a medida de arquivos destinados à gráfica antes de aprová-los.
